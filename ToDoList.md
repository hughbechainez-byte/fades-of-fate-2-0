# Mandatory Project Task Checklist

Unless the user explicitly says not to follow this file, every task in **The Fades of Fate** must satisfy and verify the following before it is reported complete.

1. **Animation floor:** Before any other work on an entity begins, its class must be known. If the class is unclear, ask first. Use these bare-minimum authored pose floors: playable hero `120-160` min / `220-320` normal / `350-500` ideal; basic enemy `45-70` min / `90-130` normal; elite enemy `150-240` normal; boss `140-200` min / `250-400` normal. Per-state guideline: idle `6/8-12/16-24`, walk `8/12-16/24`, run `8/12-16/20-24`, start/stop/pivot `3/4-6/6-8`, light attack `6/8-10/12-16`, heavy attack `8/10-14/16-20`, special `10/14-20/24-36`, hurt light `4/5-6/8`, hurt heavy `6/7-8/10-12`, knockdown `6/8/10-12`, grounded/down `4/6-8/10-12`, get-up `6/8-10/12-16`, jump start `3/4-6/6-8`, airborne `4/6-8/8-12`, air attack `6/8-10/12-16`, landing `3/4-6/6-8`, dodge `6/8-10/12-16`, grab/throw `10/14-20/24-32`, interaction `6/8-10/12-16`, victory/defeat `8/10-16/20-32`. An `(alpha)` classification may temporarily use fewer poses than the normal floor for a named light enemy, only to verify silhouette and in-game cohesion before full completion. Never duplicate, jitter, translate, or add senseless filler merely to reach a count. Continue improving animation coverage toward the researched fluid-demo target of roughly **600 meaningful actor drawings across the demo**. If an animation cannot sensibly accept more frames during a task, state the animation and reason in the post-task report.

For every task, report the animation-floor verification result alongside the task-specific test result.
