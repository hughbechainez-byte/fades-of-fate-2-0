# Mandatory Project Task Checklist

Unless the user explicitly says not to follow this file, every task in **The Fades of Fate** must satisfy and verify the following before it is reported complete.

1. **Animation floor:** Every active animation for every in-game character must contain at least five meaningful authored poses/frames. Continue improving animation coverage toward the researched fluid-demo target of roughly **600 meaningful actor drawings across the demo**. Never duplicate, jitter, translate, or add senseless filler merely to reach a count. If an animation cannot sensibly accept more frames during a task, state the animation and reason in the post-task report.

For every task, report the animation-floor verification result alongside the task-specific test result.
