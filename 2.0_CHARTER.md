# Fades of Fate 2.0 — Project Charter

**Status:** binding for all agents and developers  
**Repo:** `https://github.com/hughbechainez-byte/fades-of-fate-2-0`  
**Engine:** **OpenBOR** (ground-up). Not the original Pygame/Python demo.

## Product stance: hard break (A)

This repository is a **new game**. It is **not** a continuation, soft fork, or content port of *The Fades of Fate* (1.0 / foundation demo) unless the user **explicitly** requests a pull from that project.

### Forbidden without explicit user permission

Do **not** use from the original game (repo `the-fades-of-fate` or any archive of it):

- Campaign structure, levels, encounters, bosses (including Couch)
- Models, sprites, atlases, portraits (except Dave work listed as allowed below when already approved for 2.0)
- Stage plates, vehicles, ambient traffic systems, location-lock geography as shipping content
- Gameplay JSON, combat tables, progression, UI, audio packs
- Build/delivery scripts, Desktop package rules, or “canonical main” pointing at FoF1
- Settings, validators, schemas, or architecture that encode FoF1 product design

“It’s already in this folder” is **not** permission. Inherited seed files live under quarantine and are **reference-only when asked**.

### Allowed 2.0 content (current scope only)

Until the user expands scope, the **only** active game content is:

1. **Black Dave authored poses** (and related Dave animation sources already designated for 2.0)
2. **First backdrop / setpiece work** (I-8 underpass ground-up setpiece art and life direction)

**Nothing more** — no Shelly/Chief/KO ports, no full Chapter 1, no FoF1 enemies, no Couch, no sedan props, no FoF1 ambient car system as product.

### Engine

- **Target runtime:** OpenBOR  
- Do **not** treat the quarantined Pygame FoF1 engine as the 2.0 engine  
- New playable work targets OpenBOR project layout under `openbor/`  
- Lookdev stills and temporary capture tools may exist for art review only; they are not the shipping engine

### Original repo

- `hughbechainez-byte/the-fades-of-fate` is **not** source of truth  
- Consult it **only** when the user explicitly says to  
- Never auto-sync, never default README/AGENTS to FoF1 remotes

### Quarantine

FoF1 seed material (if present) is under:

`archive/fof1_seed_do_not_use/`

That tree is **historical import only**. Do not extend it. Do not wire it as default launch. Do not “just use the old background path.”
